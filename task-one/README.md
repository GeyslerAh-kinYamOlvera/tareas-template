# 💻 Live Coding - HTML & CSS

Código de la sesión práctica de clase impartida por el **Ing. Oscar**.

## 📌 Contenido

- **Estructura HTML5**: Uso de encabezados, párrafos y contenedores semánticos.
- **Multimedia**: Inserción de imágenes con la etiqueta `<img>` (`src` y `alt`).
- **Estilos CSS**: Maquetación de tarjetas (`.step-card`), espaciados y efectos interactivos.

## 🚀 Cómo ver el proyecto

Abre directamente el archivo `index.html` en cualquier navegador web o ejecútalo con **Live Server** en VS Code.

## 🎯 Retos y Ejercicios para la Clase

### 1. Inserción y Atributos de Imagen

- Explora las secciones existentes (`Sec one` y `Sec two`).
- Asegúrate de que cada etiqueta `<img>` tenga una URL funcional en el atributo `src` y una descripción clara y accesible en el atributo `alt`.

### 2. Creación de la Sección 3 (Tema Libre)

- En el archivo `index.html`, ubica el bloque de comentarios de la **Sección 3**.
- Maqueta una nueva tarjeta replicando la estructura aprendida:
  1. Contenedor principal con la clase `step-card`.
  2. Encabezado `<h2>` con la clase `step-title` (ej. _Sec three_, etc.).
  3. Párrafo `<p>` con una breve descripción .
  4. Imagen `<img>` con su `src` de tu perro o (enlace web de la imagen) y su atributo `alt`.
- Comprueba que la nueva tarjeta herede automáticamente los estilos visuales y el efecto _hover_ de CSS.
